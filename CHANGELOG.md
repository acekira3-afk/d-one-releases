# Changelog

## D-one 2nd EDITION ver2.32 preview

- Published the buildable preview source for inspection and testing, without bundling local user data or credentials.
- Added a separate detail window with multiple editable subnotes per task.
- Subnote window colors and character accents follow the parent task category.
- Added a character-only desktop preview mode with adjustable size.
- Added an experimental task-aware model panel for GPT, DeepSeek, and Kimi; each requires the user's own API key.
- Improved inline editing so clicking another button immediately after editing remains reliable.
- Made task loading tolerant of malformed local data.
- Kept the preview build and its local notes separate from the stable v2.31 build.

## D-one 2nd EDITION ver2.31

- Added the 2nd EDITION character theme.
- Added a new D-one application icon.
- Added character-colored categories and note backgrounds.
- Added compact single-task mode and per-task visibility controls.
- Built as a Universal 2 application for Apple Silicon and Intel Macs.
- Packaged as a drag-to-Applications DMG for public testing.
